## 数字图像处理

借鉴了很多[信号与系统](../../robo/cybernetics/readme.md)的设计，在图像数字化时，

* 采样，指连续图像被表示为离散的像素点矩阵
* 量化，指单个像素点的灰度值或色度值的离散化，量化层次越多，色彩表示约细腻

## 图像处理

图像处理一般有两个目的，第一是增强，让图片更清晰、更易观察；第二是复原，让受损
的图像更接近真实原始图像。

图像质量: 

- 图像保真度 (Fidelity): 处理后图像与原始图像之间的相似度 (忠实度, 失真度)
- 图像可懂度 (Intelligiblity): 图像内容的可读性, 指观众能提取多少有效信息. 突出图像特征(关键信息), 可以提高图像可懂度, 但可能降低图像保真度.

* 图像的美学调整（视角、构图、透视、风格等）
* 图像的[压缩](图像编码.md)，去除图像采样后的冗余
* 图像的[增强](图像增强和复原.md)，突出对象
* 图像的[去噪](图像去噪.md)
* 超分辨
